# M02 학습 예시

[실제 생성 제출 정리와 계산 참고](v1.0.0/EXAMPLE_M02.md) · [전체 프롬프트·응답 및 첨부자료](v1.0.0/M02_PROMPT_CHAIN.md)

이 실제 실행은 v1.0.0의 한 문서 자료를 사용했습니다. 요청 모델 gpt-5.6-terra가 시험용 LLM, 상위 Codex가 응시자였습니다. 직접 작문을 요구하지 않고 분석·표·브리핑·임원 답변 초안을 LLM에 맡긴 뒤 오류를 확인하고 수정·채택했습니다. 기존 답안을 알고 한 교육용 시뮬레이션이며 인간 응시 성적이나 시간 실측이 아닙니다.

v2.0.0에서는 같은 수치 제약을 부서 문서와 원장·로그에서 찾아야 합니다. 이 실행을 새 자료 탐색을 검증한 기록으로 표시하지 않습니다. 새 자료를 사용할 때는 다음과 같이 탐색 단계를 추가할 수 있습니다. 아래는 **권장 입력 예시**이며 실제 실행 응답 기록이 아닙니다.

```text
선택 문제의 필수 문서를 먼저 열고, 연결된 CSV와 부속의 파일명·기간·상태·접근 범위를 조사해줘.
계산에 필요한 키와 필터를 설명하고 현재 주간의 유효 승인 자료만 원본에서 추출해줘.
인력은 인사 마스터, 검증 스킬, 확정 배정, 휴가 최신 revision, 승인 풀을 employee_id로 대조해줘.
예산은 관리 원가센터·주차·전표 상태·서명 효력과 단위를 확인하고, 합계와 중복 위험을 검산해줘.
출처 파일·레코드 키·필터·확인 불가 범위를 표에 남기고, 그 근거로 대안과 보고/발표 초안을 생성해줘.
```

응시 중 이 학습 폴더를 자동으로 읽지 않습니다. 미리 읽었다면 연습 이력에 남깁니다.

[새 v2 CSV 원본 탐색과 출처 정정의 실제 2회차 기록](V2_RETRIEVAL_CHAIN.md)도 확인할 수 있습니다. 이는 원본 회수 단계만 점검한 별도 연습입니다.
