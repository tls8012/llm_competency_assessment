## 실제 LLM 실행의 범위

[M02의 12회차 실제 대화](../examples/m02/v1.0.0/M02_PROMPT_CHAIN.md)는 gpt-5.6-terra를 시험용 LLM으로, 상위 Codex를 응시자로 사용했습니다. 자료는 v1.0.0이며 표·발표·답변을 모델이 생성했습니다. 잘못된 차이 금액·점수 단위·비교 범위를 수정한 원문과 사용 한도 중단/재개를 보존했습니다. 응시자 역할은 기존 답안을 알고 있었고 인간의 블라인드 성능시험은 아닙니다. 공개 체인은 사용자 입력·최종 응답·첨부자료 범위이며 숨은 추론·플랫폼 시스템 프롬프트·도구 이벤트 전체는 포함하지 않습니다.

새 v2 대량 자료에 대한 전체 브라우저 시험 완주, 별도 모델 독립 채점, 실제 사람의 수행시간은 미검증입니다. 기존 8~60분은 설계상 권장값을 유지하며 실제 확대 자료량에 맞는 시간은 사용자 연습 후 조정해야 합니다. 링크·ZIP·검색/파일 실행 기능의 서비스별 지원을 보장하지 않습니다.
